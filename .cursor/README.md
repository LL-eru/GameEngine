# Cursor AI Workspace

This directory contains project-local AI guidance for C++ game engine development.

Use the seven-stage default orchestration for most engine work:

1. Architect
2. Planner
3. Specialist agent: Renderer, ECS, Memory, Resource, or another domain owner
4. Reviewer
5. Tester
6. Benchmark
7. Document

For bugs, start with Planner and Debugger-style investigation before specialist implementation.
For refactors, start with Architect and require review, benchmark consideration, and documentation.
